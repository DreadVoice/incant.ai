# Writing clearly

Sample INSTRUCTION skill. It needs nothing but context, so it runs on every provider.

## How to edit

1. Read the whole passage before changing anything.
2. Cut words that carry no information.
3. Split any sentence holding more than one idea.
4. Replace abstract nouns with the thing they stand for.
5. Read the result aloud; fix whatever trips you.
